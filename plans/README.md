## Findings considered and rejected

- `scipy` declared as a runtime dependency though only the spike script uses it: plan 005 uses `scipy.stats.rankdata` at runtime, so keep it.
- Min-max normalization makes weights/ranks depend on which companies are in the sample: already documented in
  `docs/architecture/mcdm.md` "Known limitations"; plan 003's rerun and plan 005's intervals address its consequences.
- `ranking.py` imports the private `_minmax` from `weights.py`: cosmetic; revisit only if a shared `normalize.py` is needed.
- Stale README layout: folded into plan 001.
- Gaussian spike regime feeds negative values to TOPSIS: not a bug (vector normalization is a positive per-column
  scale); only the misleading comment is fixed, in plan 003.
